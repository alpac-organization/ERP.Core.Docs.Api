# 🧭 Documentación técnica del ERP

Aquí encontrarás la **referencia de la API** del ERP Grupo Vassalli. La documentación se
autoriza en el repositorio del backend `ERP.Core.Manager.Api`, dentro del directorio **`Docs`**,
con un archivo Markdown por endpoint.

## ¿Cómo se publica?

Este sitio se actualiza **automáticamente** en cada release del backend:

1. El pipeline descarga el directorio **`Docs`** del backend.
2. Carga **solo** los Markdown que existen ahí (los endpoints sin `.md` no se publican).
3. Si no hay ningún Markdown, **no se despliega nada**.
4. Se compila con Astro Starlight y se publica en **GitHub Pages**.

- [🔌 Vista general de la API](/api/overview/) — contrato, base URL, autenticación y convenciones.
- [📘 Guías](/guides/add-documentation/) — cómo documentar un endpoint en el directorio `Docs`.
- **Endpoints por módulo** — en el menú lateral (`API`), generados a partir de los `.md` del directorio `Docs`.
