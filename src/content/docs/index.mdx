# 🧭 Documentación técnica del ERP

Aquí encontrarás la **referencia de la API** del ERP Grupo Vassalli. La documentación se
autoriza en cada repositorio del backend, dentro del directorio **`Docs`**, con un archivo
Markdown por endpoint.

## APIs documentadas

Esta documentación sincroniza los endpoints de varios backends:

| API | Repositorio | Descripción |
| --- | --- | --- |
| **Administración** | `ERP.Core.Manager.Api` | Autenticación, catálogos, nómina, reportes, notificaciones. |
| **Almacén** | `ERP.Core.Warehouse.Api` | Módulo de almacén/warehouse. |

## ¿Cómo se publica?

Este sitio se actualiza **automáticamente** en cada release de los backends:

1. El pipeline descarga el directorio **`Docs`** de cada repositorio.
2. Carga **solo** los Markdown que existen (los endpoints sin `.md` no se publican).
3. Si no hay ningún Markdown en total, **no se despliega nada**.
4. Se compila con Astro Starlight y se publica en **GitHub Pages**.
