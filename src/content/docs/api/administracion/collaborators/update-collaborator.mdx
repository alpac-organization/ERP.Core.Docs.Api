---
title: "Actualizar Colaborador"
module: "Collaborators"
---

EndPoint para actualizar la información de un colaborador existente.

## Información General

| Campo | Valor |
|-------|-------|
| **Método** | <span className="http-method patch">PATCH</span> |
| **Endpoint** | `/api/v1/companies/{company_id}/modules/{module_code}/collaborators/{id}` |
| **Descripción** | Actualiza parcialmente los datos de un colaborador dentro de una compañía y módulo. |

---

## Parámetros de Ruta (Path Params)

| Parámetro | Tipo | Requerido | Descripción |
|:---------:|:----:|:---------:|-------------|
| `company_id` | `string` | <span className="pill required">Sí</span> | Identificador único de la compañía. |
| `module_code` | `string` | <span className="pill required">Sí</span> | Código del módulo dentro de la compañía (ej. `NMI-43GW`). |
| `id` | `guid` | <span className="pill required">Sí</span> | Identificador del colaborador. |

---

## Headers

| Header | Valor | Requerido |
|--------|-------|:---------:|
| `Authorization` | `Bearer {token}` | <span className="pill required">Sí</span> |
| `Content-Type` | `application/json` | <span className="pill required">Sí</span> |

---

### Descripción de Campos (solo los actualizables)

| Campo | Tipo | Requerido | Descripción |
|---|---|---|---|
| `first_name` | `string` | <span className="pill optional">No</span> | Primer nombre. |
| `second_name` | `string` | <span className="pill optional">No</span> | Segundo nombre. |
| `third_name` | `string` | <span className="pill optional">No</span> | Tercer nombre. |
| `first_lastname` | `string` | <span className="pill optional">No</span> | Primer apellido. |
| `second_lastname` | `string` | <span className="pill optional">No</span> | Segundo apellido. |
| `identification_number` | `string` | <span className="pill optional">No</span> | Número de identificación. |
| `identification_type` | `enum (IdentificationType)` | <span className="pill optional">No</span> | Tipo de identificación. |
| `gender` | `enum (GenderType)` | <span className="pill optional">No</span> | Género del colaborador. |
| `status` | `enum (CollaboratorStatus)` | <span className="pill optional">No</span> | Estado del colaborador. |
| `working_information` | `object` | <span className="pill optional">No</span> | Información laboral. |
| `salary_information` | `object` | <span className="pill optional">No</span> | Información salarial. |

Este endpoint aplica **actualización parcial**: solo envíe los campos que desea modificar.

---

## Respuestas

### ✅ 200 OK

Al actualizar exitosamente, el endpoint responde únicamente con el código **`200 OK`**, sin body.

```
HTTP/1.1 200 OK
```

### ❌ 400 Bad Request

```json
{
  "status": 400,
  "error": {
    "type_error": "ValidationError",
    "description": "El salario debe ser mayor a cero."
  },
  "created_at": "2026-09-09 10:00:00"
}
```

### ❌ 404 Not Found

```json
{
  "status": 404,
  "error": {
    "type_error": "NotFound",
    "description": "El colaborador no existe."
  },
  "created_at": "2026-09-09 10:00:00"
}
```

### ❌ 401 Unauthorized

```json
{
  "status": 401,
  "error": {
    "type_error": "Unauthorized",
    "description": "Token de autenticación inválido o expirado"
  },
  "created_at": "2026-09-09 10:00:00"
}
```
