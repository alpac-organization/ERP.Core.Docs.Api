Para que un endpoint tenga documentación en este sitio, **se escribe un archivo Markdown en el
directorio `Docs` del backend**. La estructura y el nombre del archivo definen dónde aparece.

## Ubicación

Cada backend guarda su documentación en su directorio **`Docs`**:

| API | Repositorio | Directorio `Docs` |
| --- | --- | --- |
| Administración | `ERP.Core.Manager.Api` | `src/ERP.Core.Manager.Api/Docs/` |
| Almacén | `ERP.Core.Warehouse.Api` | `Docs/` (raíz del repo) |

```
Docs/
└── <Módulo>/<Endpoint>Docs.md
```

`<Módulo>` es una carpeta (`Collaborators`, `Payroll`, `Products`, `Movements`, …) y `<Endpoint>`
el nombre de la operación. Ejemplo real (Administración):

```
Docs/Collaborators/RegisterCollaboratorDocs.md
```

Se publica como página bajo `/api/administracion/collaborators/register-collaborator/` (para Almacén:
`/api/almacen/...`). La lista de APIs se define en **`docs.config.json`**.

## Formato del Markdown

No **requiere** frontmatter: el título se toma de la primera cabecera. Un ejemplo mínimo:

```md
# Nómina - NMI-43GW

## Registrar Colaboradores

Endpoint para registrar colaborador dentro del módulo de nómina.

## Información General

| Campo | Valor |
|-------|-------|
| **Método**      | `POST` |
| **Endpoint**    | `/api/v1/companies/{company_id}/modules/{module_code}/collaborators` |
| **Descripción** | Registra un nuevo colaborador. |
```

Puedes incluir secciones de **parámetros**, **headers**, **request body** (JSON) y **respuestas**,
como en `RegisterCollaboratorDocs.md`. Se renderiza tal cual en el sitio.

### Título (title)

El `title` de la página se deduce en este orden:

1. `title:` del frontmatter (si el archivo lo trae).
2. Primera cabecera `## ` (nombre del endpoint).
3. Primera cabecera `# `.
4. Nombre del archivo.

## Reglas del pipeline

- **Solo se publican los Markdown que existen** en `Docs`. Un endpoint sin `.md` simplemente no aparece.
- Si el directorio `Docs` no tiene ningún `.md`, el despliegue se **aborta** (no se sube nada).
- Al hacer **release** del backend, el pipeline actualiza este sitio automáticamente.

:::warning
Los archivos Markdown viven en el repo del backend (`ERP.Core.Manager.Api`). No edites aquí los
archivos bajo `src/content/docs/api/**` — se sobrescriben en cada sincronización.
:::
